# Vibro

Plateforme décisionnelle de pilotage commercial (projet E.Leclerc).

## Structure du dépôt

| Dossier | Contenu |
|---|---|
| [`docs/`](docs/index.md) | Documentation (MkDocs), source de vérité pour l'équipe et les IA |
| `data/` | Échantillon de données fourni par le client |

## Documentation

```bash
pip install -r requirements-docs.txt
mkdocs serve
```

Site : <http://127.0.0.1:8000/>. Publication automatique sur GitHub Pages à chaque push sur `main`.
